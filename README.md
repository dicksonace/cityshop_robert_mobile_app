# CityShop Mobile App

Flutter buyer app for [CityShop](https://cityunlock.net) (Ghana marketplace).

## API

Production base URL (fixed):

```
https://cityunlock.net/api/v1
```

## Run

```bash
flutter pub get
flutter run
```

## Build APK

```bash
flutter build apk --release
```

Output: `build/app/outputs/flutter-apk/app-release.apk`
